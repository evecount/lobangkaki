# Code of Conduct

LobangKaki is a community care project. We expect the same kindness in this repository that the app asks of its volunteers.

## Our standards

- Be welcoming and patient, especially with first-time contributors.
- Respect the residents this project serves: no mocking of seniors, dialects, literacy levels, or economic hardship.
- No harassment, personal attacks, or discriminatory language.
- Accept constructive feedback gracefully.

## Enforcement

Report unacceptable behaviour by opening a private report to the repository owner via GitHub. Maintainers may remove comments, close issues, or ban contributors who violate these standards.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/) v2.1.
