LobangKaki 甘榜通

A voice-first, no-sign-in community assistant for Singapore neighbourhoods — meal lobang, community club events, and activity groups, in English, Mandarin, Malay, and Tamil.

Try the live demo View the code on GitHub ⬇️ Sticker pack (ZIP)

Why it exists

Seniors and low-literacy residents are locked out by app stores, logins, and English-only portals. LobangKaki works like a familiar chat: open the page, speak, and get help — no account, no download, no personal details asked.

No phantom deals

📸 Physical proofA deal needs a live stall photo plus a ~100 m location check.
🟢 Community chopOnly volunteer-checked listings are ever spoken as verified.
🚫 Anti-prankListings flagged twice are withdrawn automatically.
🙏 Zero PIINo name, phone number, or NRIC is ever requested.

Features

  • Voice input and spoken replies in four languages (Hokkien falls back to Mandarin)
  • 123 real NEA hawker centres from Data.gov.sg, with postal-code and estate lookup
  • "Find food near me" geolocation to the closest official hawker centres
  • Live Deals board with volunteer verification, expiry, and withdrawal
  • CC events and activity groups — walking, dancerobics, wushu, karaoke
  • Share a lobang straight to WhatsApp

Run it yourself

Clone the repo, then npm install && npm run dev. Full instructions and contribution guidelines are in the GitHub repository.

LobangKaki is open source under the MIT license. The current build is a client-side simulation — demo listings are examples, not real offers.
