LobangKaki is a standalone open-source project (MIT); hackathon branding, the judge overview panel, and the pitch deck were removed — do not re-add them.

The LobangKaki experience is a client-only, in-memory simulator; no deal or volunteer attestation persists or reaches a real resident, because the project intentionally has no connected backend.
Meal tips from chat are never spoken as verified offers; only a live-camera/location-checked listing can enter the demo volunteer check, because seniors must not be sent to phantom deals.
The in-app README imports the project README directly; keep both in sync when documenting features.
Meal deal expiry uses a short client-side deadline and a periodic wall-clock check, so stale verified audio is withdrawn even after a suspended tab resumes.
Keep quick actions immediately before the chat transcript and project information after the experience, so residents reach the core task first.

Resident language uses a shared locale-copy module for speech locale and key safety responses; device/browser availability is not guaranteed, and the Hokkien label falls back to Mandarin. Meal dietary filtering only uses explicit poster declarations, never text guesses, to avoid unsafe eligibility claims.

- Desktop presentation is a centered viewport-height phone frame with no side panel, preventing clipping while preserving mobile proportions.
